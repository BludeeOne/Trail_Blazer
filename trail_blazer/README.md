# Trail Blazer

Trail Blazer was created in the idea of creating something new within nature without disturbing what natural beauty was already there. Forge new paths from any start to any end no matter the time, distance, or weather. Blaze your own trail...with TRAIL BLAZER

things used
- Flutter (Dart) — Mobile App Development
- Firebase Firestore — Trail Data Storage
- Firebase Authentication — User Login (prepared but optional)
- Firebase Storage — Trail Photo Storage
- Google Maps API — Real-Time Location Tracking
- Location Plugin — Device GPS Access
- Image Picker Plugin — Camera and Gallery Access


## Project Screens

- **Home Screen** — List of saved trails pulled from Firestore.
- **Map Screen** — Real-time trail recording with GPS and trail photo uploads.
- **Search Screen** — Fuzzy search for trails by name.
- **Trail Detail Screen** — View full trail path and uploaded photos.
